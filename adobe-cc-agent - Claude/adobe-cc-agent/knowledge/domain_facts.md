# Domain Facts — Design and Print Production

## Standard Print Bleed

| Product | Bleed |
|---|---|
| Magazine and A4 print | 3mm all sides |
| Poster and large format | 5mm all sides |
| Business card | 3mm all sides |
| Packaging | Confirm with supplier |
| Banner with hem | 20–30mm (folded and sewn) |

## Resolution Rules

| Output | Minimum | Ideal |
|---|---|---|
| Magazine and brochure | 250 ppi | 300 ppi |
| Photo book | 300 ppi | 350 ppi |
| Large format at 1m viewing distance | 100 ppi at final size | 150 ppi |
| Large format at 3m or more viewing | 72 ppi at final size | 100 ppi |
| Social media and screen | 72 ppi | 72 ppi (pixel dimensions matter more) |

---

## Binding and Page Count Rules

| Binding Type | Page Count Rule | Notes |
|---|---|---|
| Saddle stitch (stapled) | Multiples of 4 | Up to approximately 64 pages |
| Perfect bind (glued spine) | Multiples of 4, minimum ~48 pages | Spine width equals total page thickness |
| Spiral or wire-o | Any count | Add margin for binding holes |

| Paper Type | Maximum Total Ink |
|---|---|
| Coated gloss or silk | 300–330% |

| Newsprint | 220–240% |

---

## PDF Standards

| Standard | Use Case | Transparency | Colour |
|---|---|---|---|
| PDF/X-1a | Legacy print | Must be flattened | CMYK only |
| PDF/X-4 | Modern print (recommended) | Live transparency supported | CMYK + RGB + spot |
| PDF/A | Archiving | Flattened | Any with embedded profile |
| Interactive PDF | Digital and screen | Live | RGB |

Use PDF/X-4 for all new print work unless the printer specifically requests PDF/X-1a.
