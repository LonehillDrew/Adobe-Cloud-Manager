# Export Preset — Print PDF CMYK

## Preset Name
Agency_Print_CMYK_PDF-X4

## Based On
PDF/X-4:2008

## Purpose
Press-ready CMYK PDF for magazine, poster, brochure, and packaging print.

---

## Complete Settings

### General Tab
| Setting | Value |
|---|---|
| Standard | PDF/X-4:2008 |
| Compatibility | Acrobat 7 (PDF 1.6) |

### Compression Tab
| Setting | Value |
|---|---|
| Colour Images — Downsampling | Bicubic to 300 ppi for images above 450 ppi |
| Colour Images — Compression | JPEG |
| Colour Images — Quality | Maximum |
| Grayscale Images — Downsampling | Bicubic to 300 ppi for images above 450 ppi |
| Grayscale Images — Compression | JPEG |
| Grayscale Images — Quality | Maximum |
| Monochrome Images | 1200 ppi |
| Compress Text and Line Art | Yes |

### Marks and Bleeds Tab

|---|---|

### Output Tab
| Setting | Value |
|---|---|
| Colour Conversion | Convert to Destination (Preserve Numbers) |
| Destination | ISO Coated v2 300% (ECI) |
| Include Destination Profile | Yes |

| Setting | Value |
|---|---|

---

## How to Create This Preset in InDesign

1. `File > Export` — Adobe PDF (Print)
2. Set all values from the tables above
3. Click Save Preset at the top of the dialog
4. Name: Agency_Print_CMYK_PDF-X4
5. Click OK

The preset will appear in the preset dropdown for all future exports in any document.

---

## How to Share This Preset

InDesign PDF presets are stored as .joboptions files.

Export: `File > Adobe PDF Presets > Define` — select preset — click Export
Import on another machine: same menu — click Import — navigate to the .joboptions file
