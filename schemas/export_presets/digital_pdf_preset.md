# Export Preset — Digital Interactive PDF RGB

## Preset Name
Agency_Digital_RGB_Interactive

## Purpose
Screen-optimised RGB PDF for digital magazines, interactive brochures, and screen-distributed documents.

---

## Settings

### Pages
| Setting | Value |
|---|---|
| Pages | All |
| View After Export | Off |

### Interactive Elements
| Setting | Value |
|---|---|
| Hyperlinks | Include |
| Cross-References | Include |
| Bookmarks | Include |
| Media | Include All |

### Image Compression
| Setting | Value |
|---|---|
| Compression | JPEG |
| JPEG Quality | High |
| Resolution | 150 ppi |

### Colour
| Setting | Value |
|---|---|
| Colour Conversion | No Colour Conversion |
| Preserve sRGB | Yes |

### Security (optional — for confidential documents)
| Setting | Value |
|---|---|
| Printing Allowed | Low Resolution |
| Changes Allowed | None |
| Enable Copying | Off |

---

## File Size Targets

| Document Type | Target Size |
|---|---|
| Magazine 60–100 pages | 30–80MB |
| Brochure 8–16 pages | 5–15MB |
| Single-page flyer | Under 2MB |
| Email attachment | Under 10MB |

If over target: reduce JPEG Quality to Medium or drop Resolution to 100 ppi.

---

## How to Create in InDesign

1. `File > Export` — Adobe PDF (Interactive)
2. Set values from the tables above
3. InDesign Interactive PDF does not support named presets in the same way as Print PDF
4. Screenshot your settings and save to this repo as reference
5. Alternative: create a Print PDF preset with Colour Conversion set to No Conversion for full compression control
